dot.html 한 파일을 여러 파일로 나눠 줘. 이번 작업 목표는
"동작은 하나도 바꾸지 않고 파일 구조만 나누기" 하나뿐이야.
버그를 발견해도 고치지 말고 목록으로만 알려줘. 기능 추가, 이름 바꾸기, 코드 정리, 포맷 변경도 하지 마.

## 0. 원칙
- 코드 내용은 한 글자도 바꾸지 않고 "잘라서 옮기기"만 해. (예외는 아래 3번의 두 가지뿐)
- 전체 파일을 새로 쓰지 말고, 원래 코드를 그대로 복사해서 나눠.
- git 커밋은 하지 마. 검토가 끝나면 따로 커밋함.
- 이전 작업 지시는 tasks/ 폴더에 있어 (tasks/02-ai.md = AI로 찍기). 참고만 하고 다시 구현하지 마.

## 1. 결과 구조
```
rpgmaker/
  index.html        dot.html의 마크업 (<style>과 <script> 내용만 빠짐)
  css/style.css     <style> 안의 내용 그대로
  js/state.js       맨 위 상수·상태 변수 ~ 예제 캐릭터 ~ 저장 ~ 실행 취소
  js/editor.js      테마 색 ~ 편집 캔버스 ~ 도구 & 팔레트
  js/frames.js      모드 ~ 프레임
  js/preview.js     미리보기
  js/io.js          내보내기 ~ PNG 불러오기
  js/ai.js          AI로 찍기 (OpenRouter)
  js/gif.js         GIF89a 인코더 (encodeGIF, lzw)
  js/main.js        기타 ~ 시작
```
- 나누는 기준은 지금 코드에 있는 `/* ---------- 섹션 이름 ---------- */` 주석이야. 섹션 순서를 바꾸지 마.
  위 표의 파일 순서 = 원래 코드의 섹션 순서.
- dot.html은 index.html로 옮긴 뒤 삭제해 (git에 이전 버전이 남아 있음).

## 2. 불러오기 방식 (중요)
- `<script type="module">`은 쓰지 마. HTML을 더블클릭해서 열면(file://) 브라우저가 막아.
- index.html의 `</body>` 바로 앞에 일반 스크립트로, 위 표 순서대로:
  ```html
  <script src="js/state.js"></script>
  <script src="js/editor.js"></script>
  ...
  <script src="js/main.js"></script>
  ```
- `<head>`에 `<link rel="stylesheet" href="css/style.css">` (Google Fonts 링크는 그대로 유지).
- 빌드 도구, npm, 외부 라이브러리 추가 금지.

## 3. 원래 코드에서 바꿔도 되는 것 (이 두 가지만)
1. 맨 앞의 `(() => {` 줄과 맨 끝의 `})();` 줄 삭제.
   - 일반 스크립트의 최상위 let/const/function은 파일끼리 서로 보이니까, 다른 수정 없이 그대로 동작해.
   - 실제로 IIFE만 벗겨서 바깥 파일 하나로 빼 봤을 때 오류 없이 동작하는 걸 확인했어.
2. editor.js의 편집 캔버스 `new ResizeObserver(() => { sizeCanvas(editor); drawEditor(); }).observe($('#wrap'));`
   한 줄만 main.js의 "시작" 섹션 맨 앞으로 옮기기.
   - 파일 사이에서 화면이 먼저 그려지면, 프레임이 아직 없을 때 drawEditor가 불려서 오류가 날 수 있어서야.

## 4. 완료 확인 기준 (이걸 다 만족해야 함)
1. index.html을 더블클릭(file://)으로 열었을 때 콘솔 오류 0개.
2. js 파일들을 표 순서대로 이어 붙이면, 원래 dot.html의 <script> 내용과 같아야 함.
   차이는 3번의 두 가지(IIFE 두 줄 삭제, ResizeObserver 한 줄 이동)와 파일 경계의 빈 줄뿐.
3. css/style.css = 원래 <style> 내용과 동일.
4. index.html = 원래 dot.html에서 <style>, <script> 안쪽만 빠지고 link/script 태그가 추가된 것 외엔 동일.
5. 모든 기능이 이전과 똑같이 동작: 그리기, 자유/MZ 모드 전환, MZ PNG 내보내기/불러오기, GIF, JSON 저장/불러오기,
   AI로 찍기(응답 붙여넣기 포함), 되돌리기, localStorage에 저장된 이전 작업 이어받기.
6. 작업하면서 발견한 버그나 이상한 점이 있으면 고치지 말고 목록으로 보고.
