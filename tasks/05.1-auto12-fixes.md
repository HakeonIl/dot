그런데 아래 문제가 나왔어.

## 0. 원칙
- 고칠 파일: js/ai.js, 필요하면 index.html, css/style.css. 다른 파일은 건드리지 마.
- 전체 파일을 새로 쓰지 말고 필요한 부분만 고쳐.
- git 커밋은 하지 마. 검토 후 따로 함.
- 실제 브라우저에서 클릭·키 입력으로 확인해. 키 입력은 element.dispatchEvent가 아니라 진짜 키 이벤트로
  (CDP Input.dispatchKeyEvent 등). 못 하면 못 했다고 보고.

## 1. [큼] 진행 중 Esc를 누르면 진행 대화상자만 닫히고 자동 찍기는 계속됨
- 확인한 것: 자동 찍기 진행 중 Esc 키 → #aiAutoProgDlg.open = false, aiAutoRunning = true, 열린 dialog 없음.
  이 상태에서 그림 편집·되돌리기·모드 변경·수동 [찍기]가 모두 가능하고, 그동안 자동 찍기가 계속 칸을 덮어씀.
  (예: 중간에 Ctrl+Z → 시작 전으로 돌아갔다가 남은 단계 결과가 그 위에 다시 써짐)
  진행 대화상자를 다시 열 방법도 없어서 [중지]를 누를 수 없음.
- 수정:
  - #aiAutoProgDlg의 'cancel' 이벤트에서 aiAutoRunning이면 preventDefault().
  - Chromium은 사용자 클릭 없이 Esc를 연달아 누르면 cancel의 preventDefault를 무시하고 닫을 수 있어.
    그래서 'close' 이벤트에서도 aiAutoRunning이면 바로 showModal()로 다시 열어 줘 (안전장치).
  - 실행이 끝난 뒤(aiAutoRunning = false)에는 Esc가 [닫기]와 똑같이 동작 (닫고 현재 칸을 아래 정지로 옮김).
    [닫기] 처리 코드를 함수 하나로 빼서 버튼과 Esc가 같이 쓰게.

## 2. [중] 저장한 캐릭터 설명이 열 때마다 덮어써짐
- aiOpenAutoSetup이 항상 $('#aiAutoDesc').value = $('#aiPrompt').value로 채워서, 저장된 aiAutoDesc가 쓰이지 않아.
  확인한 것: 설명에 "SAVED DESC" 입력 → 새로고침 → 다시 열면 칸이 빈칸 (저장소에는 "SAVED DESC"가 그대로 있음).
- 수정: 열 때 aiAutoDesc.trim()이 있으면 그 값, 비어 있을 때만 #aiPrompt 값으로 채움.

## 3. [중] 수동 찍기와 자동 찍기가 서로를 막지 않음
- aiRunAuto는 aiBusy를 확인하지 않고, doAiGenerate·aiRunCandidates는 aiAutoRunning을 확인하지 않아.
  확인한 것: 자동 찍기 중에 [찍기]와 [12장 자동 찍기] 버튼이 둘 다 활성 상태.
- 수정:
  - 수동 찍기(후보 포함) 진행 중: [12장 자동 찍기] 비활성화. aiOpenAutoSetup·aiRunAuto도 aiBusy면 "찍는 중이에요. 끝난 뒤 다시 눌러 주세요" 토스트 후 return.
  - 자동 찍기 진행 중: [찍기]·[12장 자동 찍기] 비활성화. doAiGenerate·aiRunCandidates도 aiAutoRunning이면 같은 토스트 후 return.
  - 버튼 상태는 updateAiBusyUI 한 곳에서 aiBusy와 aiAutoRunning을 같이 보고 정하게. aiRunAuto 시작·끝에서 updateAiBusyUI 호출.

## 4. [소] 자잘한 것
1. 재시도 사이에 [중지]가 눌리면(응답이 막 도착한 순간 등) while 맨 위의 `if (aiAutoStopReq) break;`로 빠져나가는데,
   이때 걷기 단계 대상 칸이 정지 그림 복사본인 채로 남고(backup 복원 안 됨) stopped도 설정되지 않아.
   이 경로에서도 backup을 복원하고 st.status = 'stop', stopped = true로.
2. AI_AUTO_POSES.RIGHT_WALK_2 끝이 "Keep the head and torso pixels unchanged."로 face가 빠져 있어.
   다른 옆모습 걷기 문장처럼 "Keep the head, face and torso pixels unchanged."로.
3. 설정 대화상자 안내 문구가 오른쪽 AI를 골랐을 때 "AI 호출 약 12번(오른쪽 AI면 12번)"으로 나와.
   반전이면 "AI 호출 약 9번 (오른쪽도 AI로 찍으면 12번)", AI면 "AI 호출 약 12번"으로.

## 5. 완료 확인 기준
1. 자동 찍기 진행 중 Esc를 1번, 그리고 1초 안에 3번 연달아 눌러도 진행 대화상자가 열려 있고(dialog[open] 존재),
   그림 편집·Ctrl+Z가 동작하지 않음. 자동 찍기는 정상적으로 끝까지 감.
2. 실행이 끝난 뒤 Esc → 대화상자가 닫히고 현재 칸이 아래 정지로 바뀜 ([닫기]와 같음).
3. 설명에 "SAVED DESC" 입력 → 닫기 → 새로고침 → 다시 열면 "SAVED DESC". 설명을 비워 두고 AI 패널 프롬프트에 글을 쓰고 열면 그 글로 채워짐.
4. 수동 찍기 진행 중(가짜 모델 500ms 대기 동안) [12장 자동 찍기]가 비활성화. 자동 찍기 중 [찍기]와 [12장 자동 찍기]가 비활성화.
   끝나면 둘 다 다시 활성화.
5. 4-1의 경로는 실제로 만들기 어려우면 코드 리뷰로만 확인하고 그렇다고 보고.
6. 5단계 완료 기준 6~15가 여전히 통과 (특히 6 정상 완주, 8 재시도, 10 중지, 11 되돌리기 한 번, 15 360px·다크모드·콘솔 오류 0개).
