## 2. [큼] 후보 진행 중 [취소]를 누를 수 없음

  모든 후보가 끝나면 숨김.

## 3. [큼] 기본 시스템 프롬프트가 스스로 모순
- 기본 템플릿 끝에 "Line numbers like "00| " and the column ruler in the input are only coordinate references.
  Do NOT output them."이 있는데, 기본 형식인 줄번호 격자와 RLE는 {FORMAT}에서 "07| "를 붙이라고 해.
  같은 프롬프트 안에서 붙여라/붙이지 마라가 동시에 나감. (4단계 지시서에서 내가 "출력 형식 부분만 {FORMAT}으로 빼라"고 해서 생긴 문제)
- 수정:
  - 기본 템플릿의 그 문장을 "The column ruler at the top of each input grid is only a coordinate reference. Do NOT output it."으로 바꾸기.
  - 줄 번호 관련 문장은 형식 설명(aiFormatDesc) 쪽으로 옮기기:
    - 격자: "Do NOT output line numbers like "00| "; they are only coordinate references in the input."
    - 줄번호 격자 / RLE: "Start every line with its 2-digit line number and "| ", the same as the input grids."
- [보낼 프롬프트 복사]로 세 형식 각각 확인했을 때 모순되는 문장이 없어야 함.

## 4. [중] 시스템 프롬프트 칸이 비어 있어서 고치기 어려움
- 지금은 textarea가 비어 있고 비어 있으면 기본값을 씀. 기본값을 조금만 고치고 싶어도 전부 새로 써야 해.
- 수정:
  - 저장된 값이 없으면 textarea에 기본 템플릿(AI_SYS_DEFAULT)을 채워서 보여 줌.
  - "수정됨" 표시는 textarea 내용(앞뒤 공백 제외)이 기본 템플릿과 다를 때만.
  - 저장할 때 기본 템플릿과 같으면 ''로 저장 (나중에 기본 템플릿이 바뀌면 자동으로 따라가게).
  - [기본값으로]는 textarea를 기본 템플릿으로 채우고 ''로 저장.
  - textarea를 완전히 비우면 지금처럼 기본값 사용.
  - 기록의 "sys 기본/수정"도 같은 기준.

## 5. [중] 비용 평균이 항상 "-"이고, 작은 비용이 "$4e-7"로 보임
- 기록에 비용을 "비용: $0.000525" 문자열로 저장하는데, aiLogSummary는 /^\$/로 읽어서 항상 실패해.
  아주 작은 값은 String()이 "4e-7"처럼 지수 표기로 바꿔서 정규식으로도 못 읽어.
- 수정:
  - 기록 항목에 costUsd(숫자 또는 null)와 costEst(true면 추정)를 저장. 문자열 cost 필드는 없애기.
  - 화면 표시는 공통 함수 하나로: 소수점 6자리까지, 끝의 0 제거, 지수 표기 금지. 예) $0.000525, $0.0000004, 추정이면 뒤에 " (추정)".
  - 표의 "비용" 칸에는 "비용: " 접두어 없이 금액만.
  - CSV는 "비용($)" 칸에 숫자만, "비용 추정" 칸에 예/아니오.
  - 요약 평균은 costUsd로 계산.
  - 이미 저장된 옛 기록(cost 문자열만 있는 것)도 읽을 때 "$" 뒤 숫자를 꺼내서 costUsd로 바꿔 쓰기 (지수 표기 포함). 못 읽으면 null.

## 6. [중] 내용 없이 200 응답이 오면 이유를 알 수 없음
- OpenRouter는 200 응답 안에 error 객체를 넣거나, content 없이 refusal만 주는 경우가 있어.
  지금은 "빈 응답"만 뜨고 디버그 원문도 비어 있어서 무엇이 왔는지 볼 수 없어.
- 수정: callAI 결과에 text가 비어 있으면 응답 JSON 전체를 문자열로(최대 2000자) 담아서 돌려줘. (예: result.rawJson)
  화면 코드는 text가 비었을 때 rawJson을 디버그 원문과 기록 원문에 넣음.
  응답에 error.message가 있으면 실패 이유를 "빈 응답" 대신 "응답 오류: <message>"로.
- 가짜 모델에도 "!json {…}" 특수 응답을 추가해서 그 JSON이 200 응답 본문으로 온 것처럼 처리하게 해 줘. 이걸로 확인할 거야.

## 7. [소] 자잘한 것
1. 비용 추정에 응답의 실제 모델 id를 쓰고 있어 (aiCostLine의 aiLastModel, aiLogCall의 r.model).
   실제 모델 id는 날짜가 붙은 이름(…-20261001 등)으로 와서 가격표에 없을 수 있어.
   요청한 모델 이름으로 먼저 찾고, 없으면 실제 모델 id로.
2. 모델 목록을 AI 설정을 열 때만 불러와서, 새로고침 후 설정을 안 열고 찍으면 지원 여부를 몰라
   미지원 파라미터가 body에 들어가고 비용 추정도 안 돼. loadAiSettings 끝에서 aiLoadModels(false)를 한 번 불러
   시작할 때 미리 불러오기 (기다리지 않음. 실패해도 조용히).
3. batch 경고 정규식이 /batch$/i라서 "…-batch" 같은 이름에도 걸려. 지시대로 /:batch$/i.
4. 줄번호 격자 / RLE에서 AI가 입력의 열 눈금 줄("    0         1", "    0123…")까지 따라 출력하면
   "줄 번호가 없음"으로 실패해. GRID 안에서 공백으로 시작하고 숫자와 공백으로만 된 줄은 눈금 줄로 보고 무시.
   (세 형식 모두. 자동 보정 설정과 관계없이 항상 무시하고, 디버그와 기록의 보정 내용에 "눈금 줄 N개 무시" 표시)
5. 후보를 골라 적용하면 대화상자가 열린 채 그대로라서 어떤 게 적용됐는지 알 수 없어.
   적용한 후보 칸에 강조 테두리(var(--accent))와 "적용됨" 표시. 다른 후보를 고르면 표시가 옮겨 감.
6. updateAiModelInfo의 `aiModelsFailed || (!aiModels && aiModelsFailed)` 중복 조건 정리 (지난번 보고한 것).

## 8. 완료 확인 기준
1. 모델을 openai/gpt-4o-mini 같은 실제 이름으로 바꿔도 "고급" 영역(파라미터·시스템 프롬프트)이 보임.
   "가짜 응답" 칸은 test/ 모델일 때만 보임.
2. 후보 3장 진행 중 대화상자 안의 [모두 취소]를 실제로 클릭하면 세 호출 모두 취소되고 그림이 그대로임.
3. 세 형식 각각 [보낼 프롬프트 복사] 결과에 "출력하지 마라"와 "붙여라"가 같이 나오지 않음.
4. 처음 열면 시스템 프롬프트 칸에 기본 템플릿이 보이고 "수정됨"이 없음. 한 글자 고치면 "수정됨",
   [기본값으로] 누르면 사라짐. 새로고침 후에도 상태 유지.
5. 가짜 모델로 몇 번 찍은 뒤 기록 요약에 평균 비용이 숫자로 나옴. cost 0.0000004인 기록이 $0.0000004로 보임.
   CSV의 "비용($)" 칸이 숫자뿐. 4단계 때 저장된 옛 기록도 평균에 포함됨.
6. "!json {"error":{"message":"Provider returned error","code":502}}" 가짜 응답 → 실패 이유 "응답 오류: Provider returned error",
   디버그 원문과 기록 [원문]에 그 JSON이 보임.
7. 열 눈금 두 줄이 GRID 맨 위에 붙은 올바른 줄번호 격자 응답이 적용되고 "눈금 줄 2개 무시"가 표시됨.
8. 후보를 고르면 그 칸에 "적용됨" 표시. 다른 후보를 고르면 표시가 옮겨 가고, 되돌리기는 고른 횟수만큼 단계가 생김.
9. 4단계 완료 기준 1~15가 여전히 통과 (특히 file:// 콘솔 오류 0개, 360px 가로 스크롤 없음, 다크모드).
